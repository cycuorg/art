如何從零開始學 Keyboard，達到自彈自唱

目標是學會用電子琴（Keyboard）一邊彈奏、一邊唱歌，我建議你不要只把自己訓練成「會彈琴的人」，而是從一開始就朝著 自彈自唱（Keyboard Accompaniment） 的方向學習。

這兩種學習方式有些不同：

  • 一般鋼琴：重視五線譜、左右手演奏、古典曲目及技巧。
  • 自彈自唱：重視和弦、節奏、伴奏型態、歌曲調性及唱歌與彈琴的協調。

目標是能夠自己坐在 Keyboard 前面，彈著伴奏唱出喜歡的流行歌曲，其實不必先學好幾年古典鋼琴。

我把整個學習過程分成以下幾個階段，從完全初學者開始說明。

一、首先要認識 Keyboard 的基本結構

1. 認識琴鍵

Keyboard 的琴鍵分成黑鍵和白鍵。

白鍵有七個基本音：

音名 唱名
C Do（哆）
D Re（唻）
E Mi（咪）
F Fa（發）
G Sol（梭）
A La（拉）
B Si（西）

這七個音不斷循環。

初學時先找到中央的 C（中央 Do），這是很重要的起點。

2. 認識左右手的工作

自彈自唱時，左右手通常這樣分工：

  • 左手：負責低音、根音或簡單和弦。
  • 右手：負責和弦、旋律或節奏伴奏。
  • 嘴巴：負責唱歌。

初學者不必急著左右手彈得很複雜。

先學會左手彈一個低音，右手彈一個和弦，就能開始伴奏。

二、最重要的基礎：學會四個基本和弦

這是自彈自唱最重要的一環。

很多流行歌曲其實只需要四到六個基本和弦，就能彈出完整伴奏。

先從 C 大調開始，因為它全部使用白鍵，容易理解。

1. 先學四個和弦

How to Play Piano - Ultimate Beginner's Guide | Pianote

C 和弦（C Major）

音：C、E、G

左手彈 C，右手同時按 C、E、G。

4 piano exercises for beginners | Yousician

G 和弦（G Major）

音：G、B、D

左手彈 G，右手按 G、B、D。

A Minor Chord on Piano - How to Play the Am Triad | flowkey

Am 和弦（A Minor）

音：A、C、E

左手彈 A，右手按 A、C、E。

What is Harmony? - Global Music Institute

F 和弦（F Major）

音：F、A、C

左手彈 F，右手按 F、A、C。

這四個和弦非常值得練熟。

2. 練習四個和弦的循環

依序彈：

C → G → Am → F

每個和弦先按四拍：

和弦 拍子
C 1、2、3、4
G 1、2、3、4
Am 1、2、3、4
F 1、2、3、4

不斷循環。

先要求自己：

  • 和弦按得正確。
  • 換和弦不會停頓。
  • 節拍保持穩定。

等熟練以後，就能用這組和弦伴奏很多歌曲。

三、學會三種最實用的伴奏方法

這個階段會讓你從「會按和弦」進步到「聽起來像在彈一首歌」。

第一種：每拍彈一下

例如 C 和弦：

左手彈 C，右手按 C、E、G。

四拍：

1　2　3　4

每一拍彈一下。

這是最簡單的伴奏方式。

第二種：分解和弦

例如 C 和弦：

右手依序彈：

C → E → G → E

四拍循環。

這種伴奏聽起來比較柔和、優美，適合抒情歌曲。

第三種：節奏型伴奏

例如四拍歌曲：

  • 第1拍：彈和弦。
  • 第2拍：輕彈。
  • 第3拍：再彈和弦。
  • 第4拍：輕彈。

也可以搭配左手低音、右手和弦，形成流行歌曲常見的伴奏感。

我的建議： 先學第一種，再學第二種，最後學第三種。不要一開始就練複雜節奏。

四、學會左右手一起伴奏

這是從初學進入真正自彈自唱的關鍵。

1. 左手先學單音低音

例如 C 和弦：

  • 左手彈低音 C。
  • 右手彈 C、E、G。

接著換 G：

  • 左手彈 G。
  • 右手彈 G、B、D。

依序練習 C、G、Am、F。

2. 左手進階：根音加五度

例如 C 和弦：

左手彈：

C → G → C → G

右手彈：

C-E-G 和弦。

這樣會比單純彈一個低音更有節奏感。

3. 左右手配合練習

先用以下方式練習：

拍子 左手 右手
第1拍 C C-E-G
第2拍 G C-E-G
第3拍 C C-E-G
第4拍 G C-E-G

等到熟練，再把右手和弦改成不同節奏。

這個階段要注意：左右手不一定每一拍都要同時彈奏。兩隻手可以各自負責不同節奏。

五、真正開始自彈自唱：最重要的技巧

這部分是整個學習計畫的核心。

很多人會彈 Keyboard，卻無法一邊彈琴一邊唱歌，原因是兩件事需要同時使用大腦的注意力。

所以必須分階段練習。

1. 第一步：只彈琴，不唱歌

例如：

C → G → Am → F

每個和弦四拍，連續彈奏四次。

直到不必一直看手指，也能順利換和弦。

2. 第二步：彈琴，同時用嘴巴數拍

例如：

左手、右手照常彈奏，嘴巴數：

「1、2、3、4」

不要唱歌，先讓嘴巴和手的節奏分開。

3. 第三步：彈琴，同時哼旋律

選一首熟悉的歌曲。

先用「嗯、嗯、嗯」哼唱旋律，不必急著唱歌詞。

讓手繼續保持原來的和弦節奏。

4. 第四步：一邊彈琴，一邊唱歌詞

這時候才正式進入自彈自唱。

剛開始可以把伴奏簡化成：

  • 左手：每小節彈一次低音。
  • 右手：每小節彈一次和弦。
  • 歌唱：按照原本的旋律唱。

等到唱得穩定，再增加伴奏變化。

非常重要的一個觀念：

自彈自唱時，琴的工作是支撐你的歌聲，不是和歌聲競爭。

因此，右手不需要一直彈歌曲旋律。你唱旋律，雙手負責和弦及伴奏即可。

這也是專業自彈自唱者常用的方式。Roland 的自彈自唱教學也特別強調，伴奏的重點是提供歌唱旋律所需要的和聲背景，而不是讓鋼琴演奏搶走注意力。

六、學會看懂歌曲的和弦譜

這是以後能夠自己找歌、自己伴奏的必備能力。

一般流行歌曲的和弦譜，可能長這樣：

歌曲和弦範例：C 大調

C

G

Am

F

示範四小節，每個和弦一小節

C

第1小節

G

第2小節

Am

第3小節

F

第4小節

你只要看到 C，就知道要彈 C 和弦；看到 G，就換成 G 和弦。

常見和弦符號要認識

符號 意思 組成音（C大調示例）
C C大和弦 C-E-G
Dm D小和弦 D-F-A
Em E小和弦 E-G-B
F F大和弦 F-A-C
G G大和弦 G-B-D
Am A小和弦 A-C-E
Bdim 減和弦 B-D-F

其中：

  • 沒有 m 的通常是大和弦。
  • 有 m 的是小和弦。
  • 7 代表七和弦，例如 G7。
  • sus4 是掛留四和弦，例如 Csus4。

初學不必一次學完，先把 C、Dm、Em、F、G、Am 六個和弦練熟。

七、Keyboard 自彈自唱的實際練習曲目

建議先從旋律熟悉、速度較慢、和弦變化不複雜的歌曲開始。

以下是可以作為練習方向的歌曲：

第一階段：〈小星星〉

目的：熟悉琴鍵、節拍、單手及簡單和弦。

入門

第二階段：〈歡樂頌〉

目的：練習左右手配合、旋律與和弦。

初級

第三階段：〈Amazing Grace〉

目的：練習慢速抒情伴奏及歌唱配合。

初中級

第四階段：中文流行歌曲

目的：練習完整歌曲的前奏、主歌、副歌、間奏及結尾。

進階練習

我的建議是，先選自己非常熟悉的歌曲。因為你已經知道旋律，就能把注意力放在伴奏和唱歌的協調上。

八、Keyboard 每天應該怎麼練習？

我建議每天練習30分鐘，固定安排如下：

每日30分鐘練習表

暖手及認識琴鍵

5分鐘

練習 C、D、E、F、G、A、B。

四至六個基本和弦

10分鐘

練習 C、G、Am、F、Dm、Em。

左右手伴奏

10分鐘

練習低音、和弦及分解和弦。

唱歌配合伴奏

5分鐘

從哼唱開始，再唱歌詞。

每天30分鐘，比一星期只練習一次兩、三個小時更容易養成穩定的技巧。初學者也可以先以每天15至20分鐘為目標，再逐漸增加。

九、三個月自彈自唱學習進度表

如果每天能練習約30分鐘，可以按照以下進度學習。實際速度會因為音樂基礎和練習時間而不同。

時間 學習內容 預期能力
第1～2週 認識琴鍵、手指、基本節拍 能找到音符
第3～4週 C、G、Am、F和弦 能彈簡單和弦
第2個月 左右手伴奏、分解和弦 能彈簡單伴奏
第2個月底 和弦譜、歌曲節奏 能跟著歌曲彈奏
第3個月 彈琴、哼唱、唱歌配合 開始自彈自唱
第4～6個月 不同調性、轉調、節奏變化 能伴奏更多流行歌曲

十、初學者應該買哪一種 Keyboard？

如果還沒有買琴，這部分也很重要。

琴的種類 適合程度 特點
61鍵電子琴 適合入門 價格通常較親民，有自動伴奏功能的機種可幫助練習
76鍵電子琴 很適合進階 音域較廣，方便彈奏不同歌曲
88鍵數位鋼琴 適合長期學習 標準鋼琴鍵數，通常有重錘鍵盤

我會建議：

  • 如果主要目標是流行歌曲自彈自唱：61鍵或76鍵、有力度感應的 Keyboard 已經可以開始。
  • 如果希望未來也學鋼琴演奏：考慮88鍵、重錘鍵盤。
  • 如果喜歡一個人唱歌伴奏：可以考慮具有自動節奏、伴奏和弦辨識功能的電子琴。

另外要注意，Keyboard 的自動伴奏功能可以幫助你練習，但不要完全依賴自動伴奏，還是要學會自己用左右手彈和弦。

十一、初學自彈自唱最容易犯的五個錯誤

  1. 一開始就想彈完整歌曲。 應該先學會和弦及節奏。
  2. 只練右手。 自彈自唱需要左手低音與右手和弦配合。
  3. 只會按和弦，不練節拍。 和弦正確但節奏不穩，聽起來仍然不像歌曲。
  4. 一開始就彈複雜伴奏。 先用簡單和弦支撐歌聲。
  5. 彈琴時一直看手。 要逐步練到可以不必一直盯著琴鍵，才能把注意力放在歌詞與唱歌上。
