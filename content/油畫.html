從零開始學習油畫：完整入門教材與電腦數位油畫練習指南

學習油畫可以分成兩條路線：

  1. 傳統油畫（Traditional Oil Painting）：使用畫布、油畫顏料、畫筆及調色媒介，實際學習顏料厚度、色彩混合、筆觸與光影。
  2. 數位油畫（Digital Oil Painting）：使用電腦、繪圖軟體及繪圖板，模擬油畫顏料的厚塗、乾刷、堆疊、混色及筆觸。

建議初學者同時接觸這兩種方式。先用電腦熟悉構圖、明暗、色彩與筆觸，再利用實際油畫材料練習顏料的特性。這樣可以降低初期材料成本，也能更容易理解油畫的基本原理。

以下按照完全沒有繪畫經驗的初學者，安排器材、學習順序、實作方法及免費軟體。

一、首先認識油畫的基本原理

油畫與水彩最大的不同，在於油畫顏料是以油作為媒介，顏料具有一定的厚度，可以在畫布上反覆堆疊。

初學者應先理解以下六個基本概念。

1. 顏料（Pigment）

油畫顏料通常由顏料粉末與乾性植物油混合製成。

常見顏料包括：

顏色 英文名稱 用途
鈦白 Titanium White 混色、亮部
鎘黃替代色 Cadmium Yellow Hue 黃色、暖色
鎘紅替代色 Cadmium Red Hue 紅色、暖色
群青 Ultramarine Blue 藍色、陰影
酞青藍 Phthalo Blue 強烈藍色
黃赭 Yellow Ochre 土黃色、膚色
熟褐 Burnt Umber 暗部、陰影
象牙黑 Ivory Black 深色、灰色

初學時不必購買二十幾種顏色，先掌握基本顏色即可。

2. 筆觸（Brush Stroke）

油畫最重要的特色之一就是筆觸。

常見筆觸有：

  • 平塗（Flat Stroke）：均勻塗抹顏料。
  • 乾刷（Dry Brush）：使用較少顏料，在畫布上產生粗糙紋理。
  • 厚塗（Impasto）：大量堆疊顏料，形成凸起效果。
  • 點彩（Dabbing）：使用筆尖或筆刷點出細小色塊。
  • 揉合（Blending）：讓不同顏色之間產生平滑過渡。
  • 透明罩染（Glazing）：在乾燥的底層上，薄薄地覆蓋透明顏色。

初學者最值得優先練習的是平塗、乾刷、揉合與厚塗。

3. 明暗（Value）

畫一個蘋果時，即使顏色不夠漂亮，只要明暗正確，仍然可以呈現立體感。

要理解：

  • 亮部（Highlight）
  • 受光面（Light）
  • 中間調（Midtone）
  • 暗部（Shadow）
  • 投影（Cast Shadow）

初學者應先練習黑、白、灰三種明暗關係，再進入複雜色彩。

4. 色彩（Color）

色彩的三個基本要素：

  • 色相（Hue）：紅、黃、藍等顏色種類。
  • 明度（Value）：顏色的明暗程度。
  • 彩度（Saturation）：顏色的鮮豔程度。

不要一開始就追求顏色種類多，而要學會使用少量顏色調出需要的色彩。

5. 構圖（Composition）

常見構圖方式：

  • 三分法
  • 中央構圖
  • 三角形構圖
  • 對角線構圖
  • 前景、中景、背景分層

6. 油畫乾燥時間

油畫不像水彩，完成後通常不能立即收起。

油畫顏料的乾燥時間會受到顏料種類、油料、厚度、溫度與環境影響，薄塗可能數天開始表乾，厚塗則可能需要數週甚至更久。

4. 油畫媒介與安全

油畫常見媒介：

  • 精煉亞麻仁油（Refined Linseed Oil）：增加流動性、延長乾燥時間。
  • 無味礦物油替代品（Odorless Mineral Spirits）：部分產品可用於稀釋與清潔。
  • 油畫媒介（Painting Medium）：依產品說明使用。

初學者不需要同時購買很多種媒介。

安全注意事項：

  1. 保持室內通風。
  2. 不要使用食品容器存放油畫用品。
  3. 避免顏料接觸皮膚或進入口中。
  4. 不要將含油溶劑或油漬布隨意堆放，油漬布有自燃風險。
  5. 使用過的油漬布應依產品安全說明及當地規定妥善處理。
  6. 初期可以選擇水性油畫顏料，減少使用傳統溶劑的需求。

三、從零開始的實際油畫步驟

建議不要一開始就畫風景或人物。最好的入門方式是由簡單靜物開始，逐步掌握物體的立體感、光線與色彩。

第一步：學習素描與輪廓

先準備鉛筆、橡皮擦及素描紙。

練習內容：

  1. 畫圓形、方形、三角形。
  2. 畫球體、立方體及圓柱體。
  3. 畫蘋果、杯子、瓶子。
  4. 練習物體的比例與透視。

練習目標： 不需要畫得漂亮，而是要能夠正確呈現物體的形狀及位置。

第二步：練習黑白明暗

只使用：

  • 鈦白
  • 象牙黑
  • 熟褐（可選）

畫出球體，將球體分成五個明暗區域。

區域 表現方式
高光 最亮的白色
亮部 淺灰色
中間調 中灰色
暗部 深灰色
投影 最深的灰色

練習時特別注意：陰影並不只是黑色，而是受到環境光影響的顏色。

第三步：學習基本調色

先練習以下混色：

混合顏色 結果
黃色＋紅色 橙色
紅色＋藍色 紫色
黃色＋藍色 綠色
紅色＋白色 粉紅色
藍色＋白色 淺藍色
黃色＋熟褐 土黃色
藍色＋熟褐 深灰藍色

這個階段應該製作自己的色彩表，記錄每一種顏色由哪些顏料混合而成。

第四步：練習不同油畫筆觸

在畫布上劃分成六個區域：

  1. 平塗：練習均勻上色。
  2. 乾刷：練習少量顏料的粗糙質感。
  3. 厚塗：練習顏料堆疊。
  4. 點彩：練習使用筆尖。
  5. 揉合：練習兩種顏色的過渡。
  6. 刮刀：練習使用調色刀創造紋理。

每一種筆觸至少練習十次，並觀察筆刷角度、施力及顏料量對結果的影響。

第五步：完成第一幅靜物油畫

第一幅作品建議畫一顆蘋果。

操作順序：

1. 構圖

用鉛筆在畫布上簡單標示蘋果的位置及大小。

2. 底色

使用稀薄的熟褐或黃赭建立底色，讓畫布不再是純白色。

3. 建立大色塊

使用紅色、黃色及深紅色畫出蘋果的基本形狀。

4. 建立明暗

在受光面加入黃色及白色，在背光面加入深紅色與少量熟褐。

5. 建立立體感

用揉合筆觸處理明暗過渡，注意不要將所有顏色混成一團。

6. 加入高光

用少量鈦白及淺黃色表現光線反射。

7. 畫出投影

在蘋果下方加入深色投影，使蘋果看起來真正放在桌面上。

8. 完成與乾燥

依照顏料厚度及產品說明等待乾燥，避免尚未乾燥就覆蓋或包裝。

四、如果在電腦上學習油畫筆觸，應使用哪些免費軟體？

這是非常值得採用的學習方法。

數位繪畫可以反覆修改，不必擔心顏料浪費，也不必等待油畫乾燥。

我特別推薦以下三套免費軟體。

1. Krita：最推薦

首選推薦

Krita

專門用於數位繪畫，具有多種模擬傳統畫筆的筆刷引擎，適合學習油畫筆觸。

Windows、Linux、macOS；免費開源。

Krita 的優勢在於筆刷種類非常豐富，尤其適合練習：

筆刷引擎 模擬效果 練習用途
Bristle Brush 豬鬃油畫筆 傳統油畫筆觸
Color Smudge 顏色混合、揉合 油畫顏色融合
Chalk Brush 粉筆、粗糙筆觸 乾刷
Texture Brush 紋理效果 畫布及顏料質感
MyPaint Brush 自然媒材筆觸 模擬傳統畫筆

Krita 官方文件特別介紹 Bristle Brush、Color Smudge 等多種筆刷引擎，可以調整筆刷紋理、顏料厚度與混色效果。

docs.krita.org+2

特別值得練習的是 Color Smudge。

它能讓筆刷在移動時取得畫面上的顏色，再與目前筆刷顏色混合，產生類似傳統油畫揉合的效果。

官方說明：Color Smudge Brush Engine。

2. MyPaint：自然筆觸練習

MyPaint

著重自然繪畫體驗，筆刷具有鉛筆、炭筆、墨水與顏料等自然媒材風格。

Windows、Linux、macOS；免費開源。

主要特色：

  • 筆刷反應自然。
  • 支援壓力感應繪圖板。
  • 筆刷可以自行設定。
  • 可以進行自由繪畫。
  • 有適合模擬傳統顏料的筆刷。

MyPaint 的筆刷引擎甚至有顏料模型相關功能，適合練習自然筆觸。

如果希望專心練習筆觸，而不是花時間研究複雜的軟體操作，MyPaint 是不錯的選擇。

3. GIMP：輔助工具

GIMP

主要是影像編輯軟體，但也可以用於繪畫、筆刷及圖層練習。

Windows、Linux、macOS；免費開源。

適合：

  • 練習色彩調整。
  • 分析照片的明暗。
  • 練習圖層。
  • 對照原始照片與繪畫結果。
  • 修改與處理繪畫參考照片。

但如果主要目標是學習油畫筆觸，我仍然建議以 Krita 為主。GIMP 的核心定位是影像編輯，而不是專業自然媒材繪畫。

五、如何利用 Krita 練習真正的油畫筆觸？

這是我認為最值得花時間的部分。

1. 準備電腦設備

基本上只需要：

  • Windows 電腦。
  • Krita。
  • 滑鼠或繪圖板。

不過，如果希望真正模擬油畫筆觸，建議使用繪圖板。

繪圖板可以感應筆壓，讓筆觸隨著施力改變粗細及透明度。

可以考慮：

  • Wacom：產品線成熟，適合長期使用。
  • Huion：有不同價位的入門繪圖板。
  • XP-Pen：提供多種入門繪圖板。

初學不必購買有螢幕的繪圖板，普通無螢幕繪圖板就可以開始練習。

2. 在 Krita 建立第一張畫布

建議設定：

設定 數值
畫布寬度 1920 px
畫布高度 1080 px
解析度 300 DPI
色彩模式 RGB
背景 淺灰色或米白色

建立畫布後，先熟悉以下工具：

  • Brush Tool：畫筆工具。
  • Eraser Tool：橡皮擦。
  • Color Selector：選色。
  • Layers：圖層。
  • Brush Presets：筆刷預設。

3. 練習六種數位油畫筆觸

可以建立一張筆觸練習表。

揉合 Color Smudge 顏色過渡
乾刷 Texture Brush 破碎紋理
厚塗 厚重紋理筆刷 顏料堆疊感
點彩 粗糙圓形筆刷 筆尖控制

要特別注意：數位筆刷所模擬的厚塗，主要是視覺紋理效果，不等於真實顏料具有的物理高度。

每一個練習檔案都保留不同圖層：

  • Layer 1：原始參考照片。
  • Layer 2：輪廓線。
  • Layer 3：基本色彩。
  • Layer 4：明暗。
  • Layer 5：筆觸。
  • Layer 6：細節。

這樣可以隨時比較不同階段的成果。

十、最後的學習方向建議

當基本技巧掌握後，可以進一步研究三種不同的油畫風格：

  1. Claude Monet（印象派）：學習光線、色彩及快速筆觸。
  2. Vincent van Gogh（後印象派）：學習厚塗、方向性筆觸及強烈色彩。
  3. Paul Cézanne（後印象派）：學習幾何構圖、物體結構及色彩層次。

這三位畫家很適合用來研究不同的油畫筆觸。

最終建議：

先安裝 Krita，使用滑鼠練習一週，再考慮購買繪圖板。尤其要把時間放在 Bristle Brush、Color Smudge、乾刷及厚塗這四種技法上。這些練習比單純使用數位濾鏡把照片轉成油畫效果，更能真正培養油畫能力。
