從零開始學習壓克力畫與水彩畫：完整入門教材、器材、技法與實作課程

如果想從零開始學習繪畫，除了前面介紹的油畫，非常建議同時認識壓克力畫（Acrylic Painting）與水彩畫（Watercolor Painting）。

這三種媒材雖然都可以用畫筆創作，但它們的顏料特性、操作方法、乾燥時間及繪畫觀念有很大的不同。

其中：

  • 水彩畫：學習水分控制、透明度、色彩層次與留白。
  • 壓克力畫：學習色塊、筆觸、顏色堆疊、厚塗與構圖。
  • 油畫：學習顏料厚度、慢速調色、透明罩染與細膩的色彩過渡。

如果完全沒有繪畫經驗，我建議先學水彩，再學壓克力，最後再進入油畫。這不是絕對的順序，而是比較容易循序掌握繪畫基本觀念的安排。

第一部分：認識壓克力畫與水彩畫

壓克力顏料是以丙烯酸樹脂乳液作為主要黏結材料，混合顏料粉末製成。

它具有幾個重要特色：

  1. 可以用水稀釋。
  2. 乾燥後形成具有耐水性的顏料膜。
  3. 乾燥速度通常比油畫快。
  4. 可以在乾燥的顏料層上繼續作畫。
  5. 可以使用厚塗、平塗、乾刷及刮刀等技法。
  6. 可以畫在畫布、木板、紙張及經適當處理的其他表面。

1. 壓克力畫的優點

  • 不需要使用傳統油畫溶劑。
  • 不需要等待數天才能繼續下一層。
  • 顏料乾燥後不容易被水重新溶解。
  • 容易清潔，未乾燥時可用水清洗畫筆。
  • 適合初學者練習各種筆觸。
  • 可以製作接近油畫的厚塗效果。

2. 壓克力畫的缺點

  • 乾燥速度快，顏料容易在調色盤上結乾。
  • 乾燥前後可能有些微顏色變化。
  • 不容易像油畫一樣長時間揉合顏色。
  • 乾燥後不容易重新修改。
  • 需要適當控制水分，過度稀釋可能影響顏料成膜。

3. 壓克力畫可以表現哪些風格？

印象派 短筆觸、色彩並置

壓克力畫很適合初學者，因為可以先建立色彩及形狀，再逐漸增加筆觸和細節。

二、水彩畫（Watercolor Painting）

水彩顏料主要由顏料粉末、水溶性膠結材料及其他添加成分組成。

它最重要的特色是利用水分控制顏料的流動與透明程度。

水彩畫與壓克力畫最大的差異是：

水彩通常利用紙張的白色作為亮部，而不是依靠白色顏料把顏色調亮。

1. 水彩畫的優點

  • 器材相對簡單。
  • 顏料使用量少。
  • 容易攜帶。
  • 能表現透明、輕盈的色彩。
  • 適合風景、花卉、建築及旅行速寫。
  • 顏色乾燥後，許多水彩顏料仍可重新加水使用。

2. 水彩畫的缺點

  • 水分控制需要時間練習。
  • 紙張容易因水分過多而起皺。
  • 不容易完全遮蓋錯誤。
  • 顏色容易因水分過多而失去飽和度。
  • 顏料乾燥後的顏色可能比濕畫時淺。
  • 需要學會預留白色區域。

畫布如何選擇？

初學者可以選：

  1. 畫布板（Canvas Panel）：價格通常較低，適合練習。
  2. 棉布畫布（Cotton Canvas）：適合正式創作。
  3. 壓克力專用畫紙（Acrylic Paper）：方便攜帶及反覆練習。

建議第一批購買 20×25 cm 或 30×40 cm 的畫布板。

一般畫布若已經有適合壓克力使用的底料，可以直接開始作畫，不一定需要重新塗 Gesso。

四、壓克力畫的八種核心技法

1. 平塗（Flat Wash）

用寬扁筆均勻塗色。

練習：

  • 塗出一個正方形。
  • 不要留下明顯空隙。
  • 保持顏色均勻。
  • 練習不同方向的筆觸。

2. 濕畫濕（Wet-on-Wet）

在尚未乾燥的顏料上加入另一種顏色。

用途：

  • 天空漸層。
  • 花瓣色彩。
  • 背景混色。

由於壓克力乾燥很快，初學者可以使用專用延緩乾燥媒介，延長操作時間。

3. 乾刷（Dry Brushing）

操作：

  1. 使用較硬的畫筆。
  2. 沾取少量顏料。
  3. 在紙巾上擦掉多餘顏料。
  4. 輕輕刷過畫布。

適合畫樹木、岩石、草地及粗糙表面。

4. 透明罩染（Glazing）

將透明壓克力媒介與顏料混合，薄薄覆蓋在已乾燥的底色上。

例如：

先畫黃色，再覆蓋透明紅色，可以產生橙紅色的視覺效果。

注意：透明罩染應使用適當的壓克力媒介，不要單純加入大量水來代替媒介。

5. 厚塗（Impasto）

這是壓克力最有趣的技法之一。

操作：

  1. 使用 Heavy Body 顏料。
  2. 直接從顏料管取出顏料。
  3. 使用調色刀堆疊顏料。
  4. 讓每一層保留凸起紋理。

如果需要更厚的立體效果，可以使用壓克力凝膠媒介或塑形膏（Modeling Paste）。

6. 點彩（Stippling）

使用筆尖或海綿點出不同顏色。

適合：

  • 花朵。
  • 樹葉。
  • 草地。
  • 遠方景物。

7. 海綿技法（Sponge Painting）

使用海綿沾取顏料，在畫布上形成不規則紋理。

適合雲朵、樹葉、石頭及背景。

8. 刮刀技法（Palette Knife）

利用調色刀將顏料推開、刮除或堆疊，產生類似油畫的筆觸。

這種方法特別適合山景、海景及抽象畫。

上述技法也可以參考 Canson 的壓克力透明與不透明技法說明，以及 Winsor & Newton 的入門指南。

第四部分：水彩畫的器材與購買指南

一、水彩顏料有哪些種類？

水彩顏料主要分為兩種。

1. 塊狀水彩（Pan Watercolor）

顏料已經製成小塊狀，使用時用濕畫筆沾取。

優點：

  • 方便攜帶。
  • 不容易浪費。
  • 適合旅行寫生。
  • 容易控制顏料用量。

初學者可以先購買 12 色或 24 色套裝。

2. 管狀水彩（Tube Watercolor）

顏料以膏狀包裝，使用時擠到調色盤上。

優點：

  • 可以快速取得大量顏料。
  • 容易調出濃郁色彩。
  • 適合大幅畫作。
  • 可以補充塊狀水彩。

如果主要在家中練習，管狀水彩很適合；如果希望攜帶出去寫生，塊狀水彩比較方便。

第五部分：水彩畫的八種核心技法

水彩畫真正的核心不是畫筆，而是水與顏料在紙張上的互動。

同一種顏料，只要改變水量、紙張濕度或畫筆角度，就可能產生完全不同的結果。

1. 濕畫濕（Wet-on-Wet）

這是水彩最重要的技法之一。

操作方法：

  1. 用乾淨的畫筆沾水。
  2. 將水均勻塗在紙張上。
  3. 等待表面水分稍微穩定，不要有積水。
  4. 沾取顏料，輕輕接觸濕紙。
  5. 觀察顏料如何自然擴散。

效果：

  • 顏色自然融合。
  • 邊緣柔和。
  • 容易產生雲霧效果。
  • 適合天空、遠山及花朵背景。

練習時可以先畫一塊濕紙，再滴入藍色、黃色與紅色，觀察它們如何互相擴散。

2. 乾畫濕（Wet-on-Dry）

將濕潤顏料直接畫在乾燥的紙張上。

效果：

  • 邊緣清楚。
  • 顏色容易控制。
  • 適合細節。
  • 適合葉片、花瓣及建築物。

這是初學者最容易掌握的水彩技法之一。

3. 平塗（Flat Wash）

在一個區域內塗出均勻顏色。

步驟：

  1. 先調配足夠的顏料。
  2. 使用較大的圓頭筆或扁平筆。
  3. 從上方向下塗。
  4. 每一筆稍微與前一筆重疊。
  5. 保持顏料量一致。

適合畫天空、海面及大面積背景。

4. 漸層水洗（Graded Wash）

這種技法可以讓顏色由深變淺，或由淺變深。

操作：

  1. 先調出較濃的顏料。
  2. 從畫面上方開始塗。
  3. 每往下一筆，增加少量清水。
  4. 讓顏色逐漸變淡。
  5. 避免中途留下乾燥的明顯接縫。

適合天空、海面、遠山及光影效果。

5. 透明疊色（Glazing）

水彩可以利用透明顏料一層一層疊加。

例如：

  • 第一層：黃色。
  • 等待完全乾燥。
  • 第二層：薄薄的紅色。
  • 觀察重疊區域形成的橙色。

注意：必須等底層乾燥，否則會變成濕畫濕，而不是清晰的透明疊色。

6. 留白（Reserved White）

水彩的亮部通常來自紙張本身。

例如畫一朵白花：

  • 花瓣中心保留白紙。
  • 外圍畫淡藍色。
  • 花瓣邊緣增加淡紫色。
  • 花朵中心使用黃色。

這樣就能形成白色花瓣的立體感。

7. 撒鹽與特殊紋理（Salt Texture）

在尚未乾燥的水彩顏料上撒少量食鹽。

顏料乾燥後，會形成不規則的斑點與結晶狀效果。

適合：

  • 石頭。
  • 星空。
  • 雪地。
  • 特殊抽象背景。

完成後，等顏料乾透再清除鹽粒。

8. 乾刷（Dry Brush）

使用較少水分與顏料，讓畫筆在粗糙紙面上留下不連續的筆觸。

適合：

  • 草地。
  • 樹皮。
  • 岩石。
  • 木頭。
  • 建築物表面。

水彩最重要的三種紙張濕度

這個概念值得特別練習。

濕紙

顏料大幅擴散，邊緣模糊。

微濕紙

顏料適度擴散，邊緣較柔和。

乾紙

顏料容易控制，邊緣清楚。

同一種藍色顏料，在三種濕度下可能呈現完全不同的效果。

建議將三種濕度畫在同一張紙上，作為自己的水彩實驗紀錄。

水彩的水洗、濕畫濕及乾畫濕原理，可以參考 Canson 的基礎教學。

第六部分：壓克力與水彩的實際作畫流程

兩種媒材雖然有不同的操作方式，但都可以採用「構圖 → 大色塊 → 明暗 → 細節 → 完成」的基本流程。

一、壓克力畫：完成第一幅風景畫

建議第一幅作品畫一個簡單的夕陽湖景。

第一步：準備畫布

  • 使用 20×25 cm 畫布板。
  • 確認表面乾淨。
  • 如果底材尚未處理，先塗適合的 Gesso。
  • 等待底層乾燥。

第二步：構圖

使用鉛筆標出：

  • 天空與山的交界。
  • 湖面的位置。
  • 太陽的位置。
  • 前景的岩石或樹木。

不要畫太多細節。

第三步：畫天空

使用：

  • 鈦白。
  • 黃色。
  • 紅色。
  • 少量群青。

由上至下塗出天空的漸層。

第四步：畫遠山

使用群青、熟褐及少量白色。

遠山顏色應較淡，前方山脈顏色可以較深。

第五步：畫湖面

使用藍色、紫色及橙色，水平塗出水面的反射。

第六步：加入前景

使用深色畫出岩石、草地及樹木。

第七步：加入細節

使用較細的筆刷：

  • 畫出山脈輪廓。
  • 畫出湖面的反光。
  • 加入草地筆觸。
  • 加入太陽的亮光。

第八步：檢查作品

觀察：

  1. 天空是否有層次？
  2. 山脈是否有遠近？
  3. 湖面是否有反光？
  4. 前景是否有足夠對比？

完成後等待顏料充分乾燥，再依需要使用適合的壓克力保護媒介或上光劑。

二、水彩畫：完成第一幅花卉畫

第一幅作品建議畫一朵玫瑰或幾朵簡單的小花。

第一步：準備水彩紙

  • 使用 300 gsm 冷壓水彩紙。
  • 將紙張固定在畫板上。
  • 使用淡鉛筆畫出花瓣及葉片輪廓。

第二步：預留白色

在花瓣受光位置保留紙張白色。

這一步非常重要，因為水彩不容易像壓克力一樣直接用不透明顏料覆蓋錯誤。

第三步：畫第一層淡色

使用大量清水及少量粉紅色，先畫出花瓣的大致形狀。

第四步：增加第二層色彩

等待第一層完全乾燥，再加入較濃的粉紅色。

讓花瓣形成明暗層次。

第五步：畫葉片

使用黃色與藍色調出綠色。

可以使用不同深淺的綠色畫出葉片。

第六步：加入陰影

使用紫紅色及少量藍色，畫出花瓣之間的陰影。

第七步：完成細節

使用細筆畫出：

  • 花瓣邊緣。
  • 花蕊。
  • 葉脈。
  • 細小枝條。

第八步：乾燥及檢查

等待作品完全乾燥，再檢查色彩及明暗。

水彩作品一般不需要像壓克力畫那樣上透明保護漆，應避免直接接觸水分、油污及陽光。

第九部分：初學者最容易犯的錯誤

這部分非常重要，因為壓克力與水彩各有不同的問題。

一、壓克力畫常見錯誤

錯誤 原因 改善方式
顏料乾得太快 壓克力本身特性 使用延緩乾燥媒介
顏色混濁 過度揉合 讓底層乾燥後再畫
筆刷變硬 顏料乾在筆毛上 立即清洗
畫面太平 缺少明暗變化 加強亮部及暗部
顏料太稀 加入過多水 使用適當媒介
畫面太厚而龜裂 單次堆疊過厚或材料不適合 分層施工、使用適合的塑形材料

特別注意：壓克力顏料一旦乾燥，通常就不容易從畫筆上清除，因此作畫過程中應定期清洗畫筆。

二、水彩畫常見錯誤

錯誤 原因 改善方式
顏色太淡 水量過多 減少水量
顏色混濁 重複攪動濕顏料 等乾燥後再疊色
紙張起皺 紙張太薄 使用 300 gsm 水彩紙
沒有亮部 沒有預留白紙 事先規劃高光
顏料擴散過度 紙張太濕 控制紙面水分
顏色不均勻 水洗速度不一致 一次調足顏料

水彩最常見的問題是反覆在同一個區域修改，容易使紙張表面受損。

建議採取「先淡後濃、先大後小、先淺後深」的原則。

  • 不要將顏料放在食品容器中。

第十二部分：究竟應該先學壓克力，還是先學水彩？

最值得思考的問題。

壓克力畫

比較適合喜歡：

  • 強烈色彩
  • 厚重筆觸
  • 自由創作
  • 大面積色塊
  • 修改與覆蓋

水彩畫

比較適合喜歡：

  • 透明色彩
  • 自然漸層
  • 花卉及風景
  • 輕柔畫面
  • 水分變化

整體建議是：

如果希望真正建立繪畫能力，兩種媒材都值得學習，但要學會它們不同的物理特性。

水彩可以訓練你對水分、色彩透明度、留白及畫面節奏的控制；壓克力則可以訓練你對筆觸、色塊、明暗、厚度及構圖的掌握。

最後再將這些能力運用到油畫上，會比只學一種媒材更容易理解傳統繪畫。
